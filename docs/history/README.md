# Registros da interface anterior

Documentos e capturas da interface Electron/Capacitor (versões até 5.0.0),
cujo código foi removido na migração para Rust. Ficam como histórico: os
comandos, caminhos e scripts citados aqui não existem mais na árvore atual.

- `english.md`: suporte a português/inglês na interface web.
- `studio.md`: editor `.m` da página inicial web.
- `updates.md`: melhorias de estudo da v3.x.
- `screenshots/`: capturas de divulgação da interface web.
- `test-systembars/`: matriz de barras do sistema no WebView Android 14/15.

A validação da interface nativa atual está em [`docs/validation`](../validation).
